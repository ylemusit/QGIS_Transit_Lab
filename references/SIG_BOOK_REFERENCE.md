# Referencia GIS — *Sistemas de Información Geográfica* (Víctor Olaya, 2020)

## Estado

**ADOPTED AS PROJECT REFERENCE**

Este documento se incorpora como referencia teórica del proyecto `QGIS_Transit_Lab` y como apoyo conceptual para las futuras validaciones geográficas de `Transit_Data_Lab`.

## Motivo

El libro no se usa como manual operativo de QGIS, sino como base teórica para comprender y justificar decisiones sobre:

- sistemas de coordenadas y proyecciones;
- modelos vectoriales y capas;
- formatos de datos espaciales;
- calidad de los datos espaciales;
- detección, medición y gestión de errores;
- bases de datos espaciales;
- metadatos;
- análisis y consultas espaciales;
- operaciones geométricas vectoriales;
- distancias, redes y zonas de influencia.

## Aplicación al proyecto

Se utilizará como soporte conceptual para definir reglas y evidencias como:

- parada fuera o demasiado alejada del `shape`;
- discontinuidades y anomalías geométricas;
- errores de coordenadas / CRS;
- coherencia espacial entre GTFS, NeTEx y otros formatos;
- calidad posicional;
- tolerancias espaciales;
- metadatos de procedencia;
- diseño de capas de evidencia para QGIS.

## Regla de uso

La obra es una referencia conceptual. Las reglas normativas, requisitos GTFS/NeTEx/SIRI y obligaciones de compliance deberán seguir basándose en sus fuentes oficiales correspondientes.
