# 05 — Ecosistema GTFS en QGIS

## Objetivo

Catalogar plugins y flujos GTFS existentes antes de implementar funcionalidad nueva.

## Categorías a investigar

- Importación de feeds GTFS.
- Conversión GTFS → GIS.
- Visualización de rutas y paradas.
- Análisis temporal.
- GTFS-RT.
- Cobertura / accesibilidad.
- Heatmaps e isócronas.
- Edición / exportación.

## Regla estratégica

Si una capacidad ya existe con calidad suficiente en QGIS o en un plugin maduro, Transit Data Lab no debe competir con ella salvo que exista una necesidad específica de auditoría/compliance no cubierta.

## Ficha mínima por plugin

- nombre;
- URL;
- repositorio;
- licencia;
- versión;
- compatibilidad QGIS;
- última actualización;
- mantenedor;
- funcionalidad;
- dependencias;
- limitaciones;
- calidad aparente;
- posible reutilización o interoperabilidad.
